# Fitz HR — Event Promo Reel: "Protect Yourself from Underpayments" (webinar)

Fitz HR × PaySauce co-hosted webinar promo, rebuilt from the PaySauce graphic into
Fitz HR branding as a 9:16 Instagram reel.

- **Build static PNG:** `python3 scripts/setup_fonts.py && python3 scripts/build_event_promo.py`
- **Build animated reel:** `cd scripts && python3 build_event_promo_anim.py`
- **Static:** `marketing/event-underpayments-reel/fitz-hr-underpayments-webinar.png` (1080×1920)
- **Video:** `marketing/exports/fitz-hr-underpayments-webinar-reel.mp4` (~4s, text rises in, headshots slide up, then holds)
- **Presenters cutout:** `marketing/event-underpayments-reel/presenters.png` (extracted from the source graphic; the build composites it at the bottom)
